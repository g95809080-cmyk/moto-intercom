## Why

用户已确认按 2026-09-30 现状梳理执行 Android 首轮 UI 改造。当前首页不能显示正在运行的群组，主按钮把停止服务与断开车友统一叫“结束对讲”，房间输入失败会丢失，设置诊断信息挤占日常设置。

## What Changes

- 首页观察现有群组快照，活动房间提供返回入口；双人主按钮使用实际动作名称。
- 群组页分为准备、成员、当前房间音频与退出区域，失败保留当前页面输入，房主结束仍确认。
- 默认设置解释生效范围，连接诊断按需展开，介绍文案覆盖双人和最多四人。
- 记录原生 Android 视觉与交互契约，继承现有品牌与原生组件。

## Capabilities

### New Capabilities
- `android-mode-ui`: 通话模式呈现和日常设置交互。

### Modified Capabilities
无。

## Impact

仅 Android 呈现层、Activity 观察者及相关回归。保留服务和协议单写者、权限、重连与默认设置持久化规则。不采用旧 Android 改版 PRD，不改 iOS，不发布。
