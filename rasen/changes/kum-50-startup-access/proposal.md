# KUM-50 启动授权与后台运行

用户授权：优先修复 v1.2.0 跳过引导后无法通话，并加入允许后台运行申请。音频优化搁置。

## 问题与范围

发布版存在核心/可选授权路径分离、权限结果不续接启动、缺少系统位置开关检查。原始无线 BUSY 的具体手机端触发原因尚无日志，不能将缺少蓝牙权限认定为根因。

统一引导和首页启动检查。授权后仅在 Activity 恢复前台时继续启动；拒绝核心权限中止，永久拒绝可跳系统设置，拒绝蓝牙或通知仍允许手机音频。检查 Wi-Fi 与系统位置开关，缺失时进入设置并核实返回状态。引导中的授权按钮现在会在条件补齐后继续启动，文案同步说明。

加入电池优化豁免申请，首次启动解释用途；可跳过、不反复弹出；设置页保留入口并按 PowerManager 实时显示豁免状态，厂商额外后台开关只提供指引。

## 验收

- 跳过引导后补齐权限并继续，无需清数据。
- Android 6/12/13 权限分支、拒绝后重试、返回设置、Activity 等待重建覆盖。
- 位置关闭时不误报 BUSY，不跳过失败连接清理。
- 后台请求拒绝或跳过仍继续；单独打开后台设置不启动服务。
- 定向回归、全量单测、lintDebug、assembleDebug 与只读架构审查。
- 实际小米/荣耀通话和厂商后台策略需双真机复验，不以 JVM 测试替代。
