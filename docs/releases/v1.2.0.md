# 🏍️ 摩声 MotoCom v1.2.0

这次，让第一次打开摩声更轻松：先用一张图认识它，再跟着高亮按钮开始聊天。

## 新变化

- 首次打开自动展示使用说明图，介绍一对一离线对讲。
- 新手引导按真实状态提示授权、打开 Wi-Fi、启动摩声、发现车友和重新扫描。
- 引导支持跳过、中断续接与重新查看；完成后不会每次启动都弹出。
- 高亮跟随真实按钮位置，支持滚动、横屏和大字体；来电与连接过程中自动让出界面。
- 更新首页、发现页与设置页交互，并修复 Wi-Fi Direct 启动条件和忙碌重试。
- 修复音频尚未就绪时的显示逻辑，避免提前显示可以对讲。
- README 全面改为中文，下载、上手和常见问题更好找。

## 安装

下载本页 `MotoCom-v1.2.0.apk`，在 Android 6.0 及以上手机安装。版本号为 `1.2.0`，versionCode 为 `3`。

本次是 Release 构建（非 debuggable），沿用 v1.0.0 / v1.1.0 的历史个人分发证书，支持兼容签名版本覆盖安装。该证书为历史 Android debug 证书，不是应用商店生产签名；本次没有更换签名或要求卸载应用。
