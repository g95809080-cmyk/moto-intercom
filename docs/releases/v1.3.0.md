# 摩声 1.3.0+aee3b3f

本次正式发布基于用户选定的最新 main：`aee3b3f8be28b787665e4237addd0bbe4622c701`。Android versionCode 为 **4**，沿用历史分发签名，可覆盖安装。

## 更新

- 新增含房主最多四人的离线房间：六位房间码、附近发现与认证、成员状态、独立静音、重连及结束房间。
- 跳过首次引导也会在启动时补齐必要权限，避免因缺少权限一直提示无线占用。
- 新增后台运行设置入口，分开显示系统电池优化豁免状态与手机后台设置的人工确认状态。
- 修复音频就绪显示、群组查找取消与失败后的界面恢复，改善实机蓝牙认证分片传输。

本次未调整 Opus 编码音质策略。四人房间已有自动化覆盖和两台实机互听验证；四台设备同时互听、无路由器隔离环境及长时间骑行仍未完成验收。本次打包未重新进行实机听音测试。

从本版起沿用 [发布版本号约定](versioning.md)。`aee3b3f` 标识获批功能基线，实际发布源码由 GitHub Release 标签指向的提交确定。
