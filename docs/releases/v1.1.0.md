# MotoIntercom v1.1.0

## Scope

This release candidate contains the current Compose multi-route UI and the
non-device audit follow-ups:

- automatic reconnect is a persisted setting with deterministic state-machine
  behavior; disabling it affects the next unexpected Connected loss and does
  not interrupt an active recovery attempt;
- Help is a real in-app dialog;
- Send Feedback uses an explicit `ACTION_CHOOSER` around an app-created
  `ACTION_SEND` text payload and does not attach session logs, recordings, URI
  data, or URI grants;
- the API 36 instrumentation job is part of GitHub Actions;
- Room/coroutine teardown in Robolectric tests is isolated between sandboxes.

## Acceptance boundary

JVM tests, lint, APK assembly, and emulator instrumentation are automated
gates. Two-device LAN/Wi-Fi Direct/WebRTC/Bluetooth behavior, RF conditions,
manual listening quality, battery/thermal behavior, TalkBack on physical
hardware, and release-device acceptance remain deferred and must not be
described as passed by this release note.

The exact test counts, APK digest, and CI run URL are recorded after the final
source gate in the accompanying verification evidence.
