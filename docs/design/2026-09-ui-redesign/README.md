# MotoCom UI 改版 · 2026-09-05

## 目标与范围

将 Android 原生界面统一为克制的骑行仪表风格：状态清晰、主操作突出、长文本可读、触控可达。实现仍使用项目既有 Compose 页面和 Android ScrollView 宿主。最新导航按用户反馈调整为全页面固定底部三栏，见 [底部导航更新](bottom-navigation.md)。

修改范围为主页、发现车友、设置、日志、主题、图标和对应 UI 回归测试。Service、音频引擎、配对协议和连接决策未改动。MainScreen 的本次差异仅分离系统动画开关与真实连接/发现状态。用户此前的跨平台和音频改动保留。

访问日期：2026-09-05。

## 设计对照与有意调整

| 检查点 | 参考与实现处理 |
| --- | --- |
| 信息层级 | 连接状态在顶部、对讲对象为最大标题、主操作独立突出。去除重复的品牌说明。 |
| 色彩 | 固定石墨色、浅灰绿、荧光绿组合；补齐 Material 次级和容器色，避免默认紫色混入。 |
| 图标 | 信号圆环替代重复的头盔照片；设置使用描边图标；发现列表使用中性人物符号。 |
| 状态真实性 | 保留实际 transport、WebRTC、蓝牙和 VOX 事实；无假在线人数、距离、时长。 |
| 字体与留白 | 设置由密集小字改为明确分组；长设备状态完整显示；车友名称与状态分行。 |
| 容器 | 减少 Home 内部嵌套胶囊；统一细边框、圆角和无阴影白色分组。 |
| 导航 | 根据用户后续反馈采用固定底部首页 / 发现车友 / 设置三栏，去掉首页右上角菜单和设置。日志页归属设置；大屏保留详情区域。 |
| 真实文案 | 保留产品真实状态文案，未照搬参考中的宣传式发现标题；VOX 保留准确状态值。 |
| 完整性 | 设置页包含真实连接、设备和权限信息，因此比概念图更长并支持滚动。 |

## 验证

这是原生 Android 项目，使用 API 36 模拟器、ADB UI 树定位点击及原始 `screencap` 截图验证，而非浏览器或 Web 预览。截图位于 `screenshots/`；文件名含 `preview` 的图片为 debug Activity 的确定性状态样本，只证明该状态的布局，不代表真机已建立音频连接。

最终测试计数、屏幕尺寸、交互与审查结论见 [verification.md](verification.md)。
