# KUM-55：认证桥接与群组单写者

本阶段连接 BLE 三轮 PAKE、加密网络描述、独立 TCP PAKE、群组名单/信令与单写者编排。尚未启用用户界面；Service、真实音频证据和完整入口由下一单元接入。

## 实现与边界

- 公开发现只返回候选元数据，全部验证候选完成后才选择；同码多个房间交给用户选择。只有双向 PAKE 确认且未被移除者能够取得加密网络凭据，尚不占席位。
- TCP 再次独立认证；握手20秒、准入10秒、无有效消息8秒、慢写5秒截止；连接/队列均有界。房主单写者独占准入决定。
- 客户端只读名单、独立 publication 序列、当前成员/控制/链路代次限制；原始 sender 经房主验证后转发。四人六条链路分别开放。
- 网络恢复保留房间、口令、参与意图及首次失联60秒截止；独立 networkAttempt 拒绝旧回调，未完成不重复发起。TCP 使用另一个 controlAttempt。单成员媒体或发送失败不会结束健康成员。
- 全队语音就绪要求每条链路两端有效 RTP 增长、音频 I/O 和路由证据。此阶段提供证据入口，生产者尚未接入，因此不能凭 PC connected/track 声称全队可听。
