# KUM-57：实机对讲故障修复

对应 [PR #32](https://github.com/g95809080-cmyk/moto-intercom/pull/32)，基于 KUM-56 分支 `5457da4`，包含已合并的 main 权限修复 `880e3ed8`。最终代码 `cd5e6ff15ffe35212c5efd0274c162890370c975`（生产代码与 `23847fe` 相同），未合并或发布。

## 原因与修复

- 双人界面的音频就绪 setter 缺少生产调用方。现在通过同一媒体会话的 RTP 收发增长、原生音频 I/O 和前后有效路由证据发布就绪；路由/媒体代次变化撤销旧证据，正常静默不反复撤销。
- 群组失败时先执行同步清理、后发布终态，Service 已丢弃 runtime，导致界面停在查找且取消无操作对象。现在先发布已提交快照，释放时保留最终状态，并限制整个查找为 60 秒。
- 旧 BLE 固定使用 20 字节包，实机日志在连接后 20 秒关闭。现在协商 MTU 247，使用最多 244 字节包，并保留协商失败/超时的小包回退。认证本身仍限时 20 秒。
- 入会消息删除静态“语音待确认”，动态语音就绪继续由真实证据计算。
